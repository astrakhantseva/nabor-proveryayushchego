# Набор проверяющего

Набор к курсу «Искусственный интеллект в проверке и экспертизе отчетов об оценке».

Набор предназначен для проверки отчета об оценке в DeepSeek Harness, бесплатной агентской среде DeepSeek. В нем рабочая папка с правилами для модели, скрипт, который проверяет PDF на скрытый текст и готовит текст отчета по страницам, стартовые запросы и примеры контрольных строк. Набор размещен в открытом репозитории и скачивается одним архивом.

Инструкция на двух листах лежит в файле «Как начать.pdf».

## Состав

| Папка набора | Содержание |
|---|---|
| Исходные файлы | Папки «Отчет», «Документы к отчету» и «Нормы» для обезличенной копии отчета, документов к нему и текстов норм в PDF |
| Проверка скрытого текста | Скрипт проверки PDF на скрытый текст и подготовки текста по страницам, файлы его запуска для Windows и Mac |
| Рабочая папка проверки | Текст отчета, документов и норм по страницам, папка «Результаты», файл правил AGENTS.md и файл «Как пользоваться». Эта папка открывается в DeepSeek Harness |
| Запросы | Девять стартовых запросов из библиотеки запросов проверяющего и шесть примеров контрольных строк |

## Шесть шагов

### 1. Скачать набор

Страница набора [github.com/astrakhantseva/nabor-proveryayushchego](https://github.com/astrakhantseva/nabor-proveryayushchego) открывается в браузере, архив скачивается кнопкой Code и пунктом Download ZIP. Для каждого нового отчета архив распаковывается в отдельную папку.

### 2. Положить обезличенную копию отчета

Текст отчета передается на серверы DeepSeek, поэтому в набор кладется только обезличенная копия, в которой сведения о заказчике и других физических лицах заменены метками. Копия в PDF кладется в папку «Исходные файлы/Отчет» под именем Отчет.pdf, копии документов к отчету в PDF в папку «Исходные файлы/Документы к отчету», тексты норм в папку «Исходные файлы/Нормы».

### 3. Проверить и подготовить отчет

В папке «Проверка скрытого текста» запускается файл «Проверить и подготовить отчет», на Windows с расширением .bat, на Mac с расширением .command. Для работы нужен Python с сайта python.org, при первом запуске устанавливается библиотека для чтения PDF.

Перечень найденных скрытых строк выводится на экран и сохраняется в файл «Перечень скрытого текста.txt» рядом со скриптом. Каждая строка рассматривается до начала работы. Текст отчета и документов по страницам без скрытых строк сохраняется в рабочую папку, модели подается только этот текст.

### 4. Открыть рабочую папку в DeepSeek Harness

Harness скачивается с официальной страницы deepseek.com/harness, ключ API выдается в личном кабинете platform.deepseek.com и вводится в настройках моделей. Рабочей папкой выбирается «Рабочая папка проверки», а не весь набор, иначе модели станут доступны исходные PDF, контрольные строки и перечень скрытого текста. В списке режимов доступа под полем ввода выбирается Read Only, в нем запись и удаление файлов отклоняются средой, а ответы остаются в окне сессии.

### 5. Задать первый запрос с контрольной строкой

Первым сообщением новой сессии подключаются правила из файла AGENTS.md. Затем задается запрос о документах, приложенных к отчету. Справка о зарегистрированных лицах в нем служит контрольной строкой, ее отсутствие в отчете заранее устанавливается по перечню приложений. Для другого отчета контрольная позиция подбирается по файлу «Контрольные строки» в папке «Запросы».

```text
Прочитай файл AGENTS.md в рабочей папке и соблюдай его правила до конца сессии.
```

```text
Составь таблицу документов, приложенных к отчету Отчет.pdf, с номерами страниц. Выписка из ЕГРН, технический паспорт, договор купли-продажи, справка о зарегистрированных лицах. Если документа в отчете нет, так и укажи.
```

### 6. Сверить ответ со страницей

Если у контрольной позиции указана страница, ответ в работу не берется и запрос повторяется в новой сессии. Если контрольная позиция отмечена как отсутствующая, каждая строка ответа сверяется со страницей исходного PDF по указанному номеру. Нужные таблицы и тексты из ответа копируются в папку «Результаты» вручную.

## Как устроена защита

Модели подается только текст, подготовленный до начала сессии, без скрытых строк, а исходные PDF лежат вне рабочей папки. В режиме Read Only запись и удаление файлов отклоняются средой, это проверено 23 октября 2026 года на Windows. В режиме Workspace Write команды и запись файлов, в том числе вне рабочей папки, выполнялись без запроса, поэтому этот режим не выбирается.

## Ограничения

Сканы без текстового слоя модели недоступны и сверяются по изображению. Таблицы переданы строками с ячейками через знак «|», значения сверяются со страницей PDF. Закрытие выхода в сеть в Harness не подтверждено, этот запрет держится на правиле файла AGENTS.md.

## Если что-то не получилось

**Python не найден.** Python устанавливается с сайта python.org, затем файл «Проверить и подготовить отчет» запускается снова. При первом запуске нужно подключение к интернету для загрузки библиотеки.

**Запуск на Mac заблокирован.** Запуск файла, скачанного из интернета, разрешается в Системных настройках в разделе «Конфиденциальность и безопасность», затем файл запускается снова.

**В папке книга Excel или документ Word.** Файл сохраняется в PDF и кладется в папку вместо исходного, иначе скрипт его не проверит и текст в рабочую папку не попадет.
