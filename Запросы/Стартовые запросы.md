# Стартовые запросы

Девять запросов взяты без изменений из библиотеки запросов проверяющего, полная библиотека из двадцати запросов входит в справочные материалы курса. Отчет в запросах назван Отчет.pdf, в рабочей папке ему соответствует файл «Отчет/Отчет_текст.md», это указано в файле правил. Каждый запрос задается в новой сессии после первого сообщения о правилах, а ответ сверяется со страницами отчета.

```text
Прочитай файл AGENTS.md в рабочей папке и соблюдай его правила до конца сессии.
```

## 1. Перечень приложенных документов со страницами, проверенный контрольной строкой

```text
Составь таблицу документов, приложенных к отчету Отчет.pdf, с номерами страниц. Выписка из ЕГРН, технический паспорт, договор купли-продажи, справка о зарегистрированных лицах. Если документа в отчете нет, так и укажи.
```

Справка о зарегистрированных лицах служит контрольной строкой, ее отсутствие в отчете устанавливается до запроса по перечню приложений.

## 2. Наличие сведений в разделе отчета со страницей каждого сведения

```text
Укажи, содержит ли раздел 2 «Задание на оценку» отчета Отчет.pdf следующие сведения, и для каждого приведи страницу отчета. Объект оценки, права на объект оценки, цель оценки, вид стоимости, дата оценки, допущения и ограничения оценки. Если сведения нет, так и укажи.
```

## 3. Сведение, приведенное в отчете в разных местах, со всеми версиями

```text
Какая дата осмотра объекта оценки указана в отчете Отчет.pdf? Если сведения в отчете расходятся, перечисли все версии со страницами и версию не выбирай.
```

## 4. Вид стоимости, объект, права, дата оценки, подходы и методы с цитатами и версиями

```text
Выпиши из отчета Отчет.pdf вид определяемой стоимости, объект оценки, оцениваемые права, дату оценки, примененные подходы и методы. Для каждого сведения приведи дословную цитату и страницу отчета. Если сведение приведено в разных местах с разными значениями, перечисли все версии со страницами и версию не выбирай. Соответствие сведений стандартам не оценивай.
```

## 5. Применение каждого из трех подходов и обоснование применения или отказа

```text
По каждому подходу к оценке, сравнительному, доходному и затратному, выпиши из отчета Отчет.pdf, применен ли подход и каким методом. Приведи дословной цитатой со страницей обоснование применения или отказа от применения. Если обоснования в отчете нет, так и укажи. Обоснованность доводов не оценивай. Формат выхода. Таблица с колонками подход, применен ли, метод, цитата обоснования, страница.
```

## 6. Сведения отчета по каждой части требования стандарта, текст которого приложен файлом

```text
В файле Требование.txt приведен текст требования федерального стандарта оценки. Найди в отчете Отчет.pdf сведения, которыми исполняется каждая часть требования, и приведи их дословными цитатами со страницами. По каждой части дай один из выводов «сведения приведены», «сведений нет», «не подтверждено». Текст требования бери только из файла, собственные сведения о стандартах не используй. Достаточность и обоснованность сведений не оценивай.
```

Текст требования кладется в папку «Исходные файлы/Нормы» файлом Требование.txt до подготовки отчета.

## 7. Даты объекта, документов и рыночных источников с ролью и страницей

```text
Выпиши из отчета Отчет.pdf все даты, которые относятся к объекту оценки, к документам об объекте и к источникам рыночной информации. Для каждой даты укажи, к чему она относится, дословную цитату и страницу отчета. Положение дат относительно даты оценки не определяй. Формат выхода. Таблица с колонками дата, к чему относится, цитата, страница.
```

## 8. Перепроверка таблицы нарушений в новой сессии с контрольной строкой

```text
Ты видишь эту таблицу впервые. Проверь каждую строку таблицы нарушений по отчету и сними неподтвержденные, у каждой снятой строки укажи причину.
```

До перепроверки в таблицу вносится контрольная строка по файлу «Контрольные строки».

## 9. Сверка готового текста с поданным фактом и признаки машинного текста

```text
Ниже приведены поданный факт и текст замечания, подготовленный по этому факту. Сверь текст с фактом и отметь каждое утверждение, которого в факте нет. Затем отметь в тексте признаки машинного текста, шаблонный анонс перед перечислением, заголовки и нумерованный каркас внутри замечания, связки вида «таким образом», «кроме того», «в ходе проверки установлено», противопоставление вида «именно оно, а не иное», пересказ нормы без ее текста. Для каждой отметки приведи дословную цитату. Текст не переписывай.

Факт. <поданный факт>

Текст замечания. <готовый текст>
```

Вместо угловых скобок вставляются поданный факт и готовый текст замечания.
